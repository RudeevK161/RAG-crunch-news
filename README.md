Система интеллектуального поиска и анализа технологических новостей на основе архитектуры **Retrieval-Augmented Generation (RAG)**.

Проект предназначен для ответа на сложные пользовательские вопросы по материалам [TechCrunch](https://techcrunch.com) с использованием семантического поиска по векторной базе данных и генерации ответов на основе извлечённого контекста.

---

## 🎯 Основные возможности

- Семантический поиск по статьям TechCrunch
- Генерация ответов с использованием больших языковых моделей (LLM)
- Векторное хранилище на базе Qdrant
- Telegram-бот для взаимодействия с пользователем
- Административная панель на Streamlit
- Асинхронная обработка задач через Celery
- Кэширование результатов в Redis
- Автоматическая индексация новых статей

## 🚀 Быстрый старт

### 1. Клонирование репозитория

```bash
git clone https://github.com/yourusername/RAG-crunch-news.git
cd RAG-crunch-news
```

### 2. Настройка файла `.env`

В корне проекта уже присутствует файл `.env`. Перед запуском необходимо указать в нём значения основных переменных окружения, в том числе:

- **`BOT_TOKEN`** — токен Telegram-бота.  
  Получить: [@BotFather](https://t.me/BotFather)

- **`OPENAI_API_KEY`** — API-ключ для доступа к языковым моделям.  
  Получить: зарегистрироваться на [RoutesAI](https://routerai.ru) (сервис предоставляет доступ к моделям Qwen через единый API)
- параметры подключения к Redis и Qdrant.

### 3. Сборка Docker-образов

Перед первым запуском необходимо собрать Docker-образы всех сервисов.

```bash
docker compose build
```

### 4. Предварительная загрузка моделей

Команда скачивает модели эмбеддингов и генерации в каталог `models_cache/`.

```bash
docker compose run --rm model_init
```

### 5. Запуск сервисов

После загрузки моделей запустите все контейнеры в фоновом режиме.

```bash
docker compose up -d
```

### 6. Загрузка подготовленного `.pkl` файла

Скачайте подготовленный файл с эмбеддингами и метаданными из S3-хранилища.

### 7. Импорт коллекции через Streamlit

Откройте административную панель по адресу:

```text
http://localhost:8501
```

В разделе **Index** выберите тип Pickle, укажите название коллекции, загрузите скачанный `.pkl` файл, задайте размер батча (например, 100), размер вектора (384, 768, 1024 и т.д. — в зависимости от модели) и метрику расстояния (Cosine). При необходимости отметьте пересоздание коллекции.


Итог: После этого система готова к обработке пользовательских запросов через REST API, Streamlit-интерфейс и Telegram-бот.
